# 測試資料

測試程式、案例及歷次測試輸出集中於此資料夾；新增的輸出也會寫在這裡。

在專案主資料夾執行：

- PowerShell：`& .\測試資料\執行測試.ps1`
- Python：`.\.runtime\python\python.exe .\測試資料\test_document_service.py`，或使用已安裝的 Python 3。
- 桌面／手機版面：`& .\測試資料\檢查手機介面.ps1`

瀏覽器檢查使用本機已安裝的 Google Chrome。部分歷史 Excel 輔助程式需 openpyxl。
程式與案例納入 GitHub；截圖、PDF、測試頁面、結果、紀錄檔與整理清單不納入。
