賸餘款繳回簽辦工具（試作）

建議使用方式：雙擊「啟動簽辦工具.cmd」。
它會啟動本機 Python 文字擷取服務並開啟瀏覽器。使用完畢後關閉服務視窗即可停止。Python 已以免安裝方式放在 .runtime 資料夾，不需另裝套件。

公文截圖辨識：
1. 截圖至少包含「發文日期、發文字號、主旨」與主旨完整文字，不必截整份公文。
2. 在畫面最上方的截圖區點選、拖放或按 Ctrl+V 貼圖，工具會自動開始辨識。
3. Windows 可按 Win+Shift+S 截圖，再回到工具貼上。
4. 核對候選專案名稱、日期、文號，可先修正，再按「核對後，帶入下方資料」。
5. 多個專案時，從名稱欄建議選擇；找不到明確名稱時請手填。
6. 套用只更新有內容的欄位，未找到的欄位保留原資料。覆蓋已有內容前會先詢問。
7. 沒有圖片時，可展開文字區，貼上公文文字來擷取。

輸入核定數與實支數，工具自動計算差額及中文金額大寫。備妥附件並完成核對後可列印／另存 PDF。地教系統請購單號只在文件留白，交會計填寫。

直接開啟「賸餘款簽辦工具.html」也能使用；此方式由瀏覽器整理主旨。要使用 Python 整理，請透過啟動檔開啟。

離開前請下載 JSON 草稿，下次可載入。本工具不會自動保存。
本機服務僅監聽127.0.0.1，只提供工具頁與文字擷取，不開放資料夾其他公文或草稿。圖片在瀏覽器辨識；使用啟動檔時，只將OCR文字交給本機Python處理。首次OCR需連線下載Tesseract程式及繁體中文語言檔。

依同資料夾「參考-餘款繳庫簽辦單 (1).docx」製作，原始文件未修改。
本版適用「核定數－實支數」全額繳回；部分補助、分攤、利息或其他收支請依個案確認。

測試：51項專案擷取、Python API、拖貼自動辨識及核對套用檢查通過；共用19組文字案例。完整OCR以合成公文圖片實測成功，尚待實際公文截圖驗證。375、390、844、1440像素版面無水平溢出。原33項功能測試通過。

移至其他電腦時，請一併複製主HTML、啟動簽辦工具.cmd、document_service.py及.runtime資料夾。
OCR官方說明：https://github.com/naptha/tesseract.js
Python官方Windows版本：https://www.python.org/downloads/windows/
核定數擷取：OCR文字如有明確核定金額，會在候選結果顯示核定數。核對後可一併帶入下方金額欄，自動重算差額；多筆金額會保留候選供選擇。未辨識到金額時，不清空原核定數。支援4,815元、10萬2,200元等阿拉伯數字金額。
