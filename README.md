# 賸餘款繳回簽辦工具

興中國小專案賸餘款繳回簽辦工具，可在本機填寫、辨識公文截圖、檢核金額、列印 A4 簽辦單及下載 Excel。

## 下載與啟動

1. 按 GitHub 的 **Code → Download ZIP**，解壓縮後使用。
2. 直接開啟「賸餘款簽辦工具.html」即可操作，由瀏覽器整理 OCR 文字。
3. 若電腦已安裝 Python 3（含 Windows Python 啟動器），可雙擊「啟動簽辦工具.cmd」，使用本機 Python 文字整理服務。

GitHub 原始碼不包含本機 `.runtime` 免安裝 Python。原本已有 `.runtime` 的電腦可繼續沿用，不必重新安裝。

首次圖片辨識需連線下載 Tesseract 及繁體中文語言檔；圖片在瀏覽器內辨識。本機服務僅監聽 `127.0.0.1`。

## 功能

- 上傳、拖放或貼上公文截圖，核對後帶入資料。
- OCR 複製文字自動去除空格並保留換行。
- 計算核定數與實支數差額、超支警示及中文大寫。
- 依重新排版範本列印或另存 PDF、下載真正的 `.xlsx`。
- 下載與載入 JSON 草稿；工具不會自動保存資料。

Excel 與列印沿用億萬元及「新臺幣 大寫 元整（$數字）」格式，日期與文號直接相接。Excel 大寫為匯出時內容，在 Excel 修改數字後需一併核對大寫。
